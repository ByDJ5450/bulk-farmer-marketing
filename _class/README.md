# 벌크농부 클래스 — 온라인 강의 웹사이트

라이브클래스(LiveKlass) 구조를 참고한 온라인 강의 + 회원 소통 웹사이트다.
**회원가입·로그인**을 지원하며, 두 가지 모드로 동작한다.

| 모드 | 조건 | 데이터 저장 위치 | 용도 |
|------|------|----------------|------|
| **로컬 모드** | 기본값 (설정 없음) | 이 브라우저 localStorage | 화면·기능 확인, 콘텐츠 준비 |
| **서버 모드** | `js/config.js`에 Supabase 키 입력 | Supabase 서버 (무료 시작) | **실제 회원 서비스** — 모든 회원이 데이터 공유 |

## 여는 법

```
_class/index.html 파일을 더블클릭 (크롬 권장)
```

또는 로컬 서버로 (유튜브 재생·서버 모드 테스트에 더 안정적):

```bash
cd "_class" && python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 페이지 구성

| 페이지 | 파일 | 내용 |
|--------|------|------|
| 홈 | `index.html` | 히어로 + 강의 목록 + 최신 커뮤니티 글 |
| 로그인/회원가입 | `auth.html` | 이메일·비밀번호 가입, 로그인 |
| 강의 상세 | `course.html?id=강의ID` | 커리큘럼·강사 소개·수강 신청 (로그인 필요) |
| 강의실 | `classroom.html?course=강의ID` | 영상 + **회원별 진도** + 강의별 질문·소통 |
| 커뮤니티 | `community.html` | 공지·질문·자유 게시판 (글·댓글은 로그인 필요) |
| 관리자 | `admin.html` | **코치 계정 전용** — 강의·영상 링크 관리, 회원 목록, 공지 |

## 회원 체계

- **일반 회원**: 가입 → 수강 신청 → 강의실 시청·진도 체크 → 댓글·게시글
- **코치(관리자)**: 관리자 페이지 접근 + 공지 작성 + 댓글에 초록 [코치] 배지
- 비밀번호는 원문을 저장하지 않는다 (로컬 모드: SHA-256 해시 / 서버 모드: Supabase Auth)

**코치 계정 만들기**
- 로컬 모드: 회원가입 화면의 "코치 코드"에 `bulk88` 입력
- 서버 모드: 가입 후 Supabase SQL Editor에서
  `update public.profiles set role = 'coach' where email = '본인이메일';`
  (클라이언트에서는 자기 role을 못 바꾸게 막아놨다 — 보안상 서버에서만 지정)

## 서버 모드로 전환하기 (Supabase) — 약 10분

1. https://supabase.com 가입 → **New project** (무료 플랜이면 충분)
2. 왼쪽 메뉴 **SQL Editor** → New query → `sql/supabase_schema.sql` 내용 전체 붙여넣기 → **Run**
3. **Authentication → Sign In / Up → Email** 에서 *Confirm email* 끄기
   (켜두면 회원이 가입 후 메일 인증을 해야 로그인된다 — 취향대로)
4. **Project Settings → API** 에서 `Project URL`과 `anon public` 키 복사
5. `js/config.js` 를 열어 두 값을 붙여넣기
6. 사이트에서 본인 계정으로 회원가입 → 위의 SQL로 코치 지정
7. 관리자 페이지 → **"기본 강의 3종 올리기"** 버튼으로 강의 업로드 → 유튜브 링크 등록

이후 사이트를 호스팅에 올리면 (아래) 회원들이 어디서든 접속해 가입·수강할 수 있다.

**호스팅 (택 1, 둘 다 무료)**
- **Netlify Drop**: https://app.netlify.com/drop 에 `_class` 폴더를 통째로 드래그 — 1분 완료
- **GitHub Pages**: 저장소에 올리고 Settings → Pages 활성화

## 운영 방법 (코치용)

1. **영상 등록** — 유튜브에 강의 영상 업로드(미등록/일부공개 추천) → 관리자 페이지에서
   해당 강의 칸에 링크 붙여넣고 저장. 일반 링크·youtu.be·쇼츠 링크 모두 인식.
2. **공지** — 관리자 페이지 "공지 작성"
3. **질문 답변** — 코치 계정으로 강의실·커뮤니티 댓글 작성 시 [코치] 배지 자동 표시
4. **회원 확인** — 관리자 페이지 회원 목록 (이름·이메일·가입일)

## 남은 것 (실서비스 체크리스트)

- [ ] Supabase 프로젝트 생성 + `js/config.js` 키 입력 (위 가이드)
- [ ] 호스팅 업로드 (Netlify Drop 권장)
- [ ] **결제 연동** — 현재 유료 강의도 확인 후 바로 등록되는 데모. 실제 결제는
      토스페이먼츠 연동 + 서버 검증이 필요하다 (다음 단계 작업).
      임시 운영법: 계좌이체 확인 후 코치가 수동으로 수강 등록해주는 방식도 가능.
- [ ] 영상 보안 — 유튜브 "미등록"은 링크를 알면 볼 수 있다. 완전 보호가 필요하면
      Vimeo(도메인 제한) 또는 Mux 같은 유료 영상 호스팅 검토.
