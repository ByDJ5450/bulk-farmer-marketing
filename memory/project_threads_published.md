## 금지 소재 (재사용 금지)

- 유형 1×B: "55kg → 88kg" 멸치 시절 메인 스토리 (다른 에피소드는 가능)
- 유형 2×D: 단백질 섭취 타이밍 (운동 후 시간대, 카제인, 체중×1.6g)
- 유형 3×A: "많이 먹으면 무조건 벌크업?" 오해 주제
- 유형 1×E: 식욕 없어서 먹기 힘듦 → 소분 식사 해결
- 유형 3×C: 식단 없이 운동만 하는 실수
- 유형 1×C: SNS 운동 영상 비교 → 헬스장 끊음 소재
- 유형 3×B: 마른 체질 유전 한계 믿음 → 칼로리 잉여+복합 운동 3개월 8kg 증가
- 유형 2×D: 수면 회복 루틴 (성장호르몬, 7시간, 수면 루틴 3가지)
- 유형 3×E: 3개월 정체기 = 자극 정체 문제 → 점진적 과부하+6주 루틴 변경
- 유형 1×C: 처음 고중량 도전 → 어깨 부상 2개월 재활, 기초 자세 재시작
- 유형 2×F: 수강생 J님 175cm 60kg → 3개월 68kg, 원리 이해로 자립
- 유형 1×A: 유산소 끊으면 근육 보존 오해 → 저강도 유산소 병행 소재
- 유형 2×D: 칼로리 잉여 고밀도 식품 5가지 (귀리+바나나+땅콩버터, 달걀+통감자, 아보카도+통밀, 우유, 견과류)
- 유형 3×E: 직장인 퇴근 후 헬스장 못 가는 문제 → 점심 30분+주말 2회 루틴 전환
- 유형 1×C: 기록 없이 감으로만 1년 반 운동 → 정체, 기록 시작 후 점진적 과부하
- 유형 1×F: 수강생 P님 170cm 64kg 3년 무변화 → 코칭 4개월 73kg, 원리 이해 자립
- 유형 1×B: K-Classic 출전 전 마른 체형 한계 믿음 → 6개월 도전 후 클래식 피지크 3위 (대회 도전 에피소드)
- 유형 2×D: 초보자 주간 운동 볼륨 설정 (주요 근육 10~15세트, 소근육 6~10세트, 48시간 회복, 6~12회)
- 유형 3×A: 단백질 보충제 없으면 근육 못 키운다 오해 → 하루 단백질 총량이 핵심, 보충제는 보조 수단
- 유형 1×E: 주변 시선·핀잔 장애물 → "내 몸은 내가 바꾼다" 결심, 조용히 88kg 달성
- 유형 1×F: 수강생 K님 178cm 58kg 헬스장 두려움 → 코칭 4개월 후 65kg, 확신 형성이 변화의 핵심
