## 금지 소재 (재사용 금지)

- 유형 1×B: "55kg → 88kg" 멸치 시절 메인 스토리 (다른 에피소드는 가능)
- 유형 2×D: 단백질 섭취 타이밍 (운동 후 시간대, 카제인, 체중×1.6g)
- 유형 3×A: "많이 먹으면 무조건 벌크업?" 오해 주제
- 유형 1×E: 식욕 없어서 먹기 힘듦 → 소분 식사 해결
- 유형 3×C: 식단 없이 운동만 하는 실수
- 유형 1×C: SNS 운동 영상 비교 → 헬스장 끊음 소재
