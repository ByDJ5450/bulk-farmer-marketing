# 네이버 블로그 발행

## 자동 발행은 불가능하다

네이버 **블로그 글쓰기 API는 2020-05-06 종료**됐다.
광고성 글 대량 발행이 이유였고, 서비스 10년 만에 닫혔다.

개발자센터 `사용 API` 드롭다운에 **블로그 항목 자체가 없다.** 목록이 잘린 게 아니다.
앱 등록·OAuth·토큰 — 전부 필요 없다.

> 2026-08-02 확인. 근거: [뉴스핌 2020-04-13](https://www.newspim.com/news/view/20200413000737)
> `naver-openapi-guide` 문서에는 아직 writePost가 남아 있지만 **종료 전 아카이브**다.
> 그 문서를 근거로 판단하지 않는다.

브라우저 자동화(셀레니움 등)로 우회하는 방법이 있지만 **쓰지 않는다.**
네이버가 API를 닫은 이유가 정확히 그 행위이고, 계정 제재 대상이다.
검색 유입을 노리고 블로그를 하는데 계정이 날아가면 본말전도다.

## 그래서 이렇게 한다 — 붙여넣기 1회

```bash
/usr/bin/python3 _blog/to_clipboard.py _blog/{글폴더} --notify
```

본문이 **서식 그대로**(제목·표·굵기 유지) 맥 클립보드에 올라간다.
`blog.naver.com` 글쓰기 열고 본문 칸에 `Cmd+V` 하면 끝이다.

`--notify`를 붙이면 텔레그램으로 제목과 안내가 간다. 폰으로 확인하고 맥에서 붙여넣는 흐름이다.

발행 전 직접 확인할 것: **카테고리 / 태그 / 공개설정**

주 1개 기준으로 실제 손이 가는 시간은 2분 내외다.

## 글 폴더 구조

```
_blog/{slug}/
  title.txt      제목 한 줄 (100자 이내)
  content.html   본문 HTML
```

## HTML 작성 규칙

스마트에디터가 붙여넣기를 재해석하므로 태그를 단순하게 쓴다.

| 쓸 것 | 용도 |
|-------|------|
| `<p>` `<br />` | 문단·줄바꿈 |
| `<h3>` | 소제목 |
| `<strong>` | 강조 |
| `<blockquote>` | 인용 |
| `<table border="1" cellpadding="8">` | 수치 비교표 |
| `<ul><li>` | 목록 |

`<div>` 레이아웃, 인라인 `style`, 외부 이미지는 쓰지 않는다 — 붙여넣을 때 깨진다.
사진은 붙여넣기 후 에디터에서 직접 올린다.

## 왜 블로그를 유지하는가

다른 채널은 전부 알고리즘 노출이라 발행 순간이 지나면 죽는다.
블로그는 "마른 체형 벌크업", "체중 안 느는 이유" 같은 검색어로 몇 달 뒤에도 들어온다.
현재 유입이 100% 알고리즘 의존이고 검색 자산이 하나도 없다. 주 1개면 충분하다.
