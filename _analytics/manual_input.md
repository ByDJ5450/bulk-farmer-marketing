# 수동 입력 — 인스타그램 · 스레드 · 전환

> 자동 수집 경로가 없는 데이터. `performance-analyst`가 유튜브·틱톡 데이터와 합쳐 분석한다.
> 비어 있으면 해당 항목은 "데이터 없음"으로 처리되고 분석에서 빠진다.

**입력 시간 목표: 주 5분.** 게시물을 전부 옮기지 않는다. 아래 3개 표만 채운다.

---

## 1. 주간 요약 (필수 · 2분)

인스타그램 앱 → 프로필 → 프로페셔널 대시보드 → 최근 7일

| 주 시작일 | IG 도달 | IG 프로필방문 | IG 팔로워 증감 | 스레드 조회 | 스레드 팔로워 증감 | 발행 수 (IG/스레드) |
|-----------|---------|--------------|---------------|------------|------------------|-------------------|
| | | | | | | / |
| | | | | | | / |

---

## 2. 그 주의 상위 3개만 (필수 · 2분)

전부가 아니라 **가장 잘 된 3개**만. 이것만으로도 패턴은 잡힌다.

| 주 시작일 | 채널 | 주제 요약 | 도달·조회 | 저장 | 공유 |
|-----------|------|----------|----------|------|------|
| | IG / 스레드 | | | | |
| | | | | | |
| | | | | | |

> 인스타는 **저장 > 공유 > 좋아요** 순으로 중요하다. 저장이 알고리즘 확산에 가장 강하게 작용한다.

---

## 3. 전환 지표 (가장 중요 · 1분)

조회수보다 이 표가 중요하다. **목표는 조회수가 아니라 등록**이고, 지금 이 연결이 측정되지 않고 있다.

| 주 시작일 | DM 문의 | 유입 경로 | 상담 진행 | 등록 |
|-----------|---------|----------|----------|------|
| | | 유튜브 _ / IG _ / 스레드 _ / 틱톡 _ / 미상 _ | | |
| | | | | |

> **유입 경로는 DM 2단계에서 묻는다** — "혹시 어디서 보고 오셨어요?"
> (`sales-copywriter` 에이전트 DM 4단계에 포함됨)
> 이 한 줄이 쌓여야 "어떤 콘텐츠가 등록을 만드는가"를 알 수 있다.

---

## 채울 게 없는 주

빈칸으로 두지 말고 `0` 또는 `-`를 적는다. 빈칸은 "안 적었다"와 "0이었다"를 구분할 수 없다.

---

## 자동화 계획

이 파일은 임시 수단이다. Meta API 연동이 끝나면 1·2번 표는 자동으로 채워진다.
3번 전환 지표는 DM 대화에서 나오는 값이라 **연동 후에도 수동으로 남는다.**
진행 상황은 `_analytics/meta_api_setup.md` 참조.
