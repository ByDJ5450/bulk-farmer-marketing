# 수동 입력 데이터 — 인스타그램 · 스레드

> 인스타그램과 스레드는 자동 수집 경로가 없습니다. 아래 표를 채워두면
> `performance-analyst`가 유튜브·틱톡 데이터와 합쳐 분석합니다.
> **비어 있으면 해당 채널은 "데이터 없음"으로 처리되고 분석에서 빠집니다.**

**입력 주기:** 주 1회 (월요일 권장) — 지난 7일치만 추가하면 됩니다.

---

## 인스타그램

인스타그램 앱 → 프로필 → 프로페셔널 대시보드 → 콘텐츠 인사이트에서 확인합니다.

| 발행일 | 유형 | 주제 요약 | 도달 | 저장 | 공유 | 프로필 방문 | 링크 클릭 |
|--------|------|----------|------|------|------|------------|----------|
| | 카드뉴스 / 릴스 / 단일 | | | | | | |

> **저장 > 공유 > 좋아요** 순으로 중요합니다. 저장이 많은 게시물이 알고리즘 확산에 가장 유리합니다.

## 전환 지표 ⭐ 가장 중요

조회수보다 이 표가 중요합니다. **목표는 조회수가 아니라 등록**이고, 지금 이 연결이 측정되지 않고 있습니다.

| 주차 | DM 문의 수 | 유입 경로 (알고 있으면) | 상담 진행 | 등록 |
|------|-----------|----------------------|----------|------|
| | | 예: 유튜브 3 / 인스타 1 / 미상 2 | | |

> **유입 경로 파악 방법:** DM 응대 1단계에 *"혹시 어디서 보고 오셨어요?"* 를 넣으면
> 다음 리포트부터 조회수 ↔ 문의 연결이 가능해집니다.
> (`sales-copywriter` 에이전트의 DM 4단계 참조)
