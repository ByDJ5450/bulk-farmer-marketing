# 수동 입력 — 전환 지표 · 네이버 블로그

> API로 얻을 수 없는 것만 남겼다. `performance-analyst`가 자동 수집 데이터와 합쳐 분석한다.
> 비어 있으면 해당 항목은 "데이터 없음"으로 처리되고 분석에서 빠진다.

**입력 시간 목표: 주 2분.** 표 2개가 전부다.

> 2026-08-02 정리. 인스타·스레드 지표는 Meta API 연동이 끝나 자동 수집된다.
> 이 파일에서 뺐다. 3주 동안 안 채워진 이유가 분량이었다면, 이제 그 핑계는 없다.

---

## 1. 전환 지표 (가장 중요)

조회수보다 이 표가 중요하다. **목표는 조회수가 아니라 등록**이고, 지금 이 연결이 측정되지 않고 있다.

| 주 시작일 | DM 문의 | 유입 경로 | 상담 진행 | 등록 |
|-----------|---------|----------|----------|------|
| | | 유튜브 _ / IG _ / 스레드 _ / 틱톡 _ / 블로그 _ / 미상 _ | | |
| | | | | |
| | | | | |

> **유입 경로는 DM 2단계에서 묻는다** — "혹시 어디서 보고 오셨어요?"
> (`sales-copywriter` 에이전트 DM 4단계에 포함됨)
> 이 한 줄이 쌓여야 "어떤 콘텐츠가 등록을 만드는가"를 알 수 있다.

---

## 2. 네이버 블로그

블로그는 발행 API도 통계 API도 없다. 유일하게 수동으로 남는 채널이다.
`blog.naver.com` → 내 블로그 → **통계** → 일간/주간

| 주 시작일 | 총 조회수 | 검색 유입 비중 | 유입 검색어 상위 3개 | 발행 수 |
|-----------|----------|--------------|---------------------|--------|
| | | % | | |
| | | | | |

> **검색 유입 비중**이 핵심 지표다. 이게 올라가야 블로그를 하는 의미가 있다.
> 초반에는 이웃·SNS 유입이 대부분이고, 검색 유입은 2~3개월 뒤부터 붙는다.
> 유입 검색어는 다음 글 주제를 정하는 근거가 된다.

## 채울 게 없는 주

빈칸으로 두지 말고 `0` 또는 `-`를 적는다. 빈칸은 "안 적었다"와 "0이었다"를 구분할 수 없다.
