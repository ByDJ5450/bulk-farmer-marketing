주간 채널 성과 리포트를 생성한다. 대화 상대는 없다. 질문하지 말고 끝까지 수행한 뒤 결과 파일을 남긴다.

절차:

1. `.claude/agents/performance-analyst.md`를 읽고 그 규칙을 그대로 따른다.
   특히 --flat-playlist 금지, video ID 기준 중복 제거, 중앙값 우선 판단, n 병기 규칙을 지킨다.

2. `_analytics/` 에서 가장 최근 리포트를 읽는다. 지난번 "다음 주 기획 인풋"이 실행됐는지
   이번 데이터로 대조한다.

3. 유튜브 전수 수집 (롱폼 + 쇼츠). PATH에 yt-dlp가 있어야 한다:
   export PATH="/Library/Frameworks/Python.framework/Versions/3.14/bin:$PATH"

4-1. 스레드 수집 (Threads API). `~/.config/bulkfarmer/meta.env` 에 자격증명이 있다.
     게시물 목록 + 게시물별 지표(views/likes/replies/reposts/quotes) + 계정 지표.
     상세 절차는 performance-analyst.md "스레드" 섹션 참조.
     **토큰 만료 점검 필수** — THREADS_TOKEN_EXPIRES 가 7일 이내면 갱신하고 결과를 알린다.
     토큰 값은 어떤 출력에도 찍지 않는다.

4. 틱톡 수집 (--ignore-errors 필수). 성공/실패 개수를 리포트에 명시한다.
   실패율 60% 초과 시 `yt-dlp -U` 후 1회 재시도하고, 그래도 안 되면 "틱톡 수집 실패"로 기록한다.

4-2. 인스타그램 수집 (Instagram Graph API). 자격증명은 같은 meta.env.
     미디어 목록 + 게시물별 지표(reach/saved/shares/likes/comments/profile_visits)
     + 계정 지표(reach/profile_views/website_clicks).
     media_type(IMAGE/VIDEO/CAROUSEL_ALBUM)별로 나눠서 본다 — 카드뉴스는 CAROUSEL_ALBUM.
     **website_clicks·profile_visits가 전환에 가장 가까운 지표다.** 반드시 리포트에 넣는다.
     IG_TOKEN_EXPIRES 7일 이내면 갱신한다.

5. `_analytics/manual_input.md`의 전환 지표(3번 표)를 읽는다. 비어 있으면
   추정하지 말고 "데이터 없음"으로 명시한다. (1·2번 표는 이제 자동 수집됨)

6. 리포트를 `_analytics/{YYYY-MM-DD}_channel_report.md`로 저장한다.
   형식은 performance-analyst.md의 "리포트 형식" 섹션을 따른다.

7. 전략 문서(`CLAUDE.md`, `_context/youtube_strategy.md`)의 전제 중 이번 데이터와
   어긋나는 것이 있으면 리포트 3번 섹션에 정리한다. 문서를 직접 수정하지는 않는다.

8. 텔레그램으로 요약을 보낸다. 자격증명은 `~/.config/bulkfarmer/telegram.env`에 있다.

   source ~/.config/bulkfarmer/telegram.env
   curl -s -X POST "https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/sendMessage" \
     -H "Content-Type: application/json" \
     -d "$(python3 -c '...')"     # chat_id, parse_mode=HTML, text 를 JSON으로 구성

   메시지 형식 (600자 이내, 폰에서 읽는다):
     <b>📊 주간 성과 리포트</b>
     {날짜}
     · 유튜브 쇼츠 중앙값 {값} ({전주 대비 ±%})
     · 유튜브 롱폼 중앙값 {값} ({전주 대비 ±%})
     · 틱톡 {수집 성공 n개} / 인스타·스레드 {데이터 유무}
     <b>이번 주 발견</b>
     {가장 중요한 것 1~2개, 각 한 줄}
     <b>다음 주</b>
     {늘릴 것 / 줄일 것 각 한 줄}
     전문: _analytics/{파일명}

   토큰 노출 금지: 로그나 출력에 TELEGRAM_BOT_TOKEN 값을 절대 찍지 않는다.

9. 5~8단계 중 어디서든 실패하면, 실패 사실을 텔레그램으로 보낸다.
   조용히 끝나면 안 된다. 예: "⚠️ 주간 리포트 실패 — yt-dlp 수집 단계. 로그: _analytics/cron.err.log"

주의:
- 중간 스크립트 파일(.py, .sh)을 만들지 않는다. Bash 인라인으로 실행한다.
- 지난주 대비 변화가 없으면 "변화 없음"이라고 쓴다. 억지로 발견을 만들지 않는다.
- 성과가 하락했으면 하락했다고 쓴다.
- 마지막 줄에 한 줄 요약을 출력한다: "리포트 저장: {경로} / 핵심 발견: {한 줄}"
