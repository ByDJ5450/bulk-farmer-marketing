# 스레드 첨부 이미지 라이브러리

초안 JSON의 `image` 필드에 **파일명만** 적으면 워커가 알아서 붙인다.

```json
{ "index": 8, "image": "jh_measure.jpg", "text": "..." }
```

발행 시 R2에 올려 공개 URL을 만들고 → Threads IMAGE 게시물로 발행 →
Meta가 이미지를 가져간 뒤 R2 객체를 지운다. 저장 비용은 거의 0이다.

**이미지 업로드가 실패해도 글은 텍스트로 나간다.** 사진 때문에 글을 못 내보내는 건 손해다.
이 경우 텔레그램으로 따로 알린다.

## 규격

- 가로 1,200px · JPEG · 500KB 이내
- **얼굴이 나오는 사진은 수강생 동의를 받은 것만 쓴다**
- 화면에 박힌 자막은 그대로 둬도 된다. 실제 영상이라는 증거가 된다

## 추가하는 법

```bash
/usr/bin/python3 _repurpose/fetch_source.py <영상ID>          # 자막·메타
yt-dlp -f "bv*[height<=720]+ba" --download-sections "*MM:SS-MM:SS" ...
ffmpeg -ss <초> -i clip.webm -frames:v 1 -q:v 2 out.jpg
```

뽑은 뒤 1,200px로 줄여 이 폴더에 넣고 위 표에 한 줄 추가한다.
표에 없는 파일은 초안 생성기가 못 쓴다.
