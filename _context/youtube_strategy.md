### 3-1. 포맷 운영 원칙

```

  └ 목표: 주 1~2개 발행

### 쇼츠 훅 전환 (중요)

하락한 쇼츠와 대박 쇼츠의 차이는 소재가 아니라 **훅의 성격**이다.

| 정체성 호명형 (살아있음) | | 정보 전달형 (하락) | |
|---|---|---|---|
| 몸 안크는 사람 특징 3가지 | 45,493 | 스쿼트는 허리에 안 좋은 걸까? | 1,765 |
| 벌크업 이걸 이겨내야 합니다 | 32,307 | 몸 좋은 사람들이 7대 운동을 고집하는 이유 | 1,517 |

정보형 소재라도 **훅은 정체성으로 연다.** 검증 중인 가설이며, 정체성형 쇼츠 3개 발행 후 중앙값 1,648과 비교한다.

```

## 7. 영어 콘텐츠 전략

> **2026-07-31 정정.** 이전 버전은 "영어 롱폼 3편 평균 855로 저조 → 잠정 중단"이라고 기록했으나
> **이는 데이터 오류였다.** 영어 제목 영상은 별도 영상이 아니라 YouTube 자동 번역 제목이며,
> 한국어 원본과 **동일한 video ID**다. 같은 영상을 둘로 세어 조회수를 나눠 계산한 결과다.
>
> ```
> video ID 3tqxv0YAk_0
>   = "Revealing the Standard 'Upper Body 2-Split' Routine..."  (자동 번역)
>   = "멸치 탈출을 위한 '상체 2분할' 정석 루틴 공개"             (원제)
> ```

**현재 상태:** 실제 영어 전용 콘텐츠는 쇼츠 1편(1,915)뿐이다. 영어 확장은 **아직 시도하지 않은 실험**이지, 실패한 실험이 아니다.

**방향:** 재판단 대상. 한국어 고성과 쇼츠의 영어 버전 2~3개로 소규모 테스트 후 결정한다.
현 시점에서 "영어 지양"을 전제로 기획하지 않는다.

**재발 방지:** 수집 시 `--flat-playlist`를 쓰지 않는다. 이 옵션이 자동 번역 제목을 반환한다.
중복 판정은 제목이 아니라 video ID로 한다. (`performance-analyst` 에이전트에 명시됨)
