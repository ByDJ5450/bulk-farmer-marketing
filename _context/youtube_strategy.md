## 3. 콘텐츠 전략 방향

### 3-1. 포맷 운영 원칙

```
쇼츠 (60초 이내)
  └ 주력 노출 채널 — 알고리즘 유입 담당
  └ 목표: 주 3~5개 발행
  └ 핵심: 첫 3초 훅 + 리스트/반전 구조

롱폼 (10~16분)
  └ 신뢰·전환 채널 — 시청자를 팬으로 전환
  └ 목표: 주 1개 발행
  └ 핵심: 실제 케이스 + 구체적 방법 + 트레이너 스토리

※ 20분 이상 롱폼은 지양 (현재 채널 성과 기준)
```

### 3-2. 제목 공식 (검증된 패턴 우선 사용)

```
[공식 1] 타겟 정체성 + N가지 + 특징/실수/방법
  예: "멸치라면 반드시 아는 벌크업 실수 3가지"

[공식 2] 감정 자극 + 행동/상황 묘사
  예: "벌크업, 이걸 못 참으면 평생 멸치입니다"

[공식 3] 실제 케이스 스토리
  예: "주 3회 운동해도 체중 안 느는 마른 비만 남자"

[공식 4] 단순화 + 즉시성
  예: "멸치 탈출? 이 운동 3가지만 하면 됩니다"

[공식 5] 프로젝트/도전 모집
  예: "벌크업 90일 프로젝트 1기 모집합니다"
```

### 3-3. 섬네일 방향

- 트레이너 얼굴 + 텍스트 오버레이 조합
- 숫자 강조 (3가지, 4주, 1시간 등)
- Before/After 나란히 배치
- 표정: 놀람 > 진지 (쇼츠 기준)
- 배경색: 브랜드 컬러 세이지 그린(`#5B9B75`) 또는 살구 핑크(`#F2B5A0`) 활용
