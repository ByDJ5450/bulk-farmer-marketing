## 1. 숏폼 화면 제목 (2줄, 줄당 12자 이내)

### 어미 — 실제 발행 제목에서 나온 것만 쓴다

| 어미 | 실제 사례 |
|---|---|
| `~걸까?` | 스쿼트는 허리에 안 좋은 걸까? |
| `~다고?` `~라고?` | 2달 만에 몸이 이렇게 변했다고? |
| `~하세요!` `~보세요!` | 벌크업 안되는 이유, 혹시 여러분도 점검해보세요! |
| `~합니다` `~안됩니다!` | 멸치 탈출 이대로는 평생 실패합니다. / 굶으면 절대 벌크업 안됩니다..! |
| 쉼표 + 반전 | 벤치 80kg 실패, 근데 왜 웃지? |

### 자주 쓰는 부품

- 정체성 호명: `멸치` `어좁이` `마른 비만` `몸 안 크는 사람` `ET`
- `충격적인 진짜 이유` / `특징·실수 N가지` / `이것부터 알아야합니다` / `~하면 생기는 일`
- 수치 반전: "많이 먹는다면서 하루 1,565kcal?" — 숫자는 구체적으로, 반올림 최소화

### 금지 (AI 티의 실체 — 2026-08-08 재작성에서 잡힌 것들)

- 반말 평서 종결: ~~"반만 하고 있다"~~ → "반만 하고 계십니다!" 또는 질문형
- 소설체 묘사: ~~"그런데 웃는다"~~ → "근데 왜 웃지?"
- 기호 수식: ~~"근육 1kg = 1,500만 원"~~ → "근육 1kg이 1,500만 원이라고?" (`→`는 수치 변화 표기에만 허용: 30.5→35cm)
- 문어체 대구: ~~"완벽하다던 자세, 밀어보면 압니다"~~ → "내 스쿼트 자세 진짜 괜찮은 걸까?"
- 영어 제목 (For Bulk-Up 류 — 키워드 표면적 0, 감사에서 확인)

## 3-1. 두 박자 구조 (2026-08-10 추가 — 실코퍼스에서 가장 흔한 뼈대)

실제 발행 제목의 절반이 `앞말? 뒷말!` 두 박자다. 숏폼 2줄 제목은 이 뼈대에 얹는 게 기본값:

- "살만 찌는게 벌크업? 이걸 지켜야 합니다!" → "완벽한 스쿼트? 밀면 무너집니다"
- "벌크업 필수는 보충제? 벌크업 망하는 이유" → "등 자극 없는 분? 일단 누우세요!"

그리고 제목에 **벌크업·멸치·마른·몸** 같은 앵커 단어가 하나는 있어야 한다.
운동 기술 용어(장두·날개뼈 리듬)만으로 제목을 만들지 않는다 — 타겟이 자기 얘기인 줄 모른다.

## 4. 판정 방법

제목을 쓰고 나서 "이게 이 채널에 이미 올라가 있는 제목들 사이에 섞여 있으면
티가 나는가?"를 묻는다. 티가 나면 다시 쓴다. 기준 코퍼스는 실제 발행 제목이지
이 문서의 요약이 아니다 — 애매하면 채널 제목 목록을 직접 본다.
