# 리얼 후기 대본 가이드 — 광고 같지 않은 말

> 2026-08-05 도입. 후기 콘텐츠가 통하는 이유는 광고처럼 안 들려서다.
> 목표는 더 좋은 카피가 아니라 **카피 냄새를 아예 없애는 것.**
> F주제(사회적 증거) 콘텐츠 — 후기 릴스·쇼츠, 수강생 인터뷰 영상에 적용한다.

---

## PART 0. 벌크농부 대원칙 (이 문서 전체보다 우선)

- **모든 발언은 실제 수강생 원자료에서 나와야 한다.** 망설임·흠·감탄까지도.
  `student-story` 인터뷰 4번(신청 전 망설임)·7번(가장 힘들었던 순간) 답변이
  "작은 흠"의 원료다. **원자료에 없는 발언을 지어내지 않는다** — 리얼함을
  연출하려고 가짜 흠을 만들면 그게 바로 광고다
- 원자료 발언의 재배열·발췌는 된다. 새 문장 창작은 수강생 확인을 거친다
- 해석을 붙이지 않는다 — 인물 심리를 대신 설명하면 광고 문구로 읽힌다.
  사실만 적고 멈춘다

## PART 1. 광고 말투 vs 리얼 말투

| 광고 말투 | 리얼 말투 |
|---|---|
| "코칭이 제 몸을 완전히 바꿨어요." | "아 근데 솔직히 이렇게 먹을 줄 몰랐거든요? 근데 먹고 있어요." |
| "추천하는 이유 세 가지를 알려드릴게요." | "처음엔 PT랑 뭐가 다르지 싶었는데..." |
| 깔끔하게 완성된 문장 | 말 흐리기, 스스로 정정, "아니 근데", "솔직히" |
| 군더더기 없음 | 가벼운 군더더기가 오히려 핵심 — 대본 없다는 신호 |
| 장점을 설명함 | 장점을 깨달은 순간을 1인칭으로 말함 |

## PART 2. 리얼함의 규칙

- 1인칭, 지금 반응하는 말투. 기능(커리큘럼) 설명은 3인칭 티가 난다
- **작은 흠 하나 필수** — 망설임, 실수, "처음엔 반신반의했는데" 같은 순간.
  광고와 후기를 가르는 결정적 한 줄. 단, PART 0 — 실제 발언에서만 가져온다
- 광고 단어 금지: "인생템", "강추", "미쳤다" 남발, "무조건 하세요".
  좋았으면 형용사 말고 **좋았던 순간**을 말하기
- 광 내지 말고 구체적으로 — "살이 붙었어요"보다 "바지가 허벅지에서 걸렸어요"
- **한 사람에게 말하기** — "여러분 모두" 금지. 친구 한 명에게 보내는 음성 메시지처럼
  (트레이너 내레이션의 "여러분" 호명 규칙은 트레이너 콘텐츠용이다.
  **수강생 목소리 후기에는 적용하지 않는다** — 화자가 다르다)

## PART 3. 30초 대본 구조

1. **리액션 콜드오픈** (0:00–0:03) — 인사 없이, 반응 중간부터.
   카메라가 실제 순간을 잡은 것처럼
2. **구체적인 장면** (0:03–0:15) — 이게 유용했던 실제 상황 하나.
   요일, 하던 일, 의심까지 구체적으로
3. **솔직한 한마디** (0:15–0:20) — 아쉬운 점이나 망설였던 이유 하나.
   **여기가 후기의 심장** (인터뷰 4·7번 답변)
4. **친구에게 한 줄** (0:20–0:25) — 친구가 물어보면 해줄 말 한 문장
   (인터뷰 12번 답변)
5. **소프트 CTA** (0:25–0:30) — "궁금하면 프로필에 링크 있어요" 정도의 온도.
   세일즈 금지

형식은 `_context/reels_script_guide.md`의 초 단위 2열(화면/음성) 대본으로 쓴다.

## PART 4. 체크리스트

- [ ] 광고 단어 금지 목록 위반이 없는가
- [ ] 작고 솔직한 흠이 최소 하나 있는가 — **그리고 실제 원자료에 있는 발언인가**
- [ ] 대본이 아니라 친구한테 남긴 음성 메시지처럼 읽히는가
- [ ] 기능(커리큘럼) 나열이 어디에도 없는가
- [ ] CTA가 맨 끝에, 낮은 온도로 있는가
- [ ] 개인차 고지 포함했는가 ("개인에 따라 결과가 다를 수 있습니다" — 캡션에)
