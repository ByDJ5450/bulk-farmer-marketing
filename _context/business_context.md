# 벌크농부 비즈니스 맥락

## 사업 개요

벌크농부는 마른 체형을 가진 사람들을 대상으로 한 **1:1 벌크업 코칭 서비스**다. 운동·식단 처방에 그치는 일반적인 PT와 달리, 수강생이 스스로 벌크업을 실행할 수 있는 기초 지식과 사고 체계를 함께 전달하는 것을 핵심 차별점으로 한다.

---

## 서비스 구조

### 핵심 상품
- **1:1 벌크업 코칭 프로그램** (판매 중)
  - 현재: 초기 코호트 중심으로 후기 수집 단계
  - 향후: 차수 및 개월 수를 점진적으로 확장
- **온라인 강의** (개발 중, 2026-07 기준 미출시)
  - 1:1 코칭의 지식 전수 파트를 다수 대상으로 확장하는 상품
  - 커리큘럼·가격·일정 미확정 — 콘텐츠에서 확정 정보처럼 언급 금지
  - 출시 전까지는 사전예약·대기자 명단 형태로만 언급 가능

### 코칭 내용
1. 벌크업 기초 이론 교육 (왜 벌크업이 일어나는지, 원리 이해)
2. 개인 맞춤 운동 루틴 구성법 전수
3. 개인 맞춤 식단 구성법 전수
4. 앱을 통한 데이터 기록 및 노하우 축적 습관 형성
5. 꾸준한 실행을 위한 1:1 동행 지원

### 기존 PT와의 차별점

| 기존 PT / 유튜브 | 벌크농부 |
|-----------------|---------|
| 운동 방법만 알려줌 | 운동 원리와 이유를 함께 이해시킴 |
| 식단만 봐줌 | 스스로 식단을 구성하는 능력을 키움 |
| 트레이너 의존적 | 수강생의 자립을 목표로 함 |
| 일시적 결과 | 데이터 축적으로 지속적 성장 |

## 고객 전환 여정

```
[인지] SNS 콘텐츠 발견 (공감형 게시물)
   ↓
[관심] 트레이너 스토리 및 변화 결과 확인
   ↓
[고민] "나도 될 수 있을까" 라는 의심 단계
   ↓
[신뢰] 수강생 후기 및 Before/After 사례 확인
   ↓
[전환] 1:1 코칭 신청
```

### 단계별 담당

| 단계 | 담당 | 산출물 |
|------|------|--------|
| 인지 | 숏폼 PD, 스레드 작가 | 쇼츠·릴스, 공감형 단문 |
| 관심 | 유튜브 기획자, 스레드 작가 | 롱폼, 트레이너 스토리 |
| 고민 | 카드뉴스 디렉터 | 오해 교정·체크리스트 슬라이드 |
| 신뢰 | `student-story` | 후기 기반 Before/After 콘텐츠 |
| 전환 | `sales-copywriter` | DM 응대·모집 공고·상세페이지·상담 스크립트 |

## 마케팅 전략

### 채널
- **인스타그램** (주력): 슬라이드형 카드 콘텐츠, 피드 게시물
- **스레드 (Threads)**: 텍스트 기반 공감형 단문 콘텐츠

### 발행 전략
- 하루 **5~10개** 게시물 발행
- 타겟 고객이 현재 처한 상황에 맞는 **공감형 카피** 중심
- 벌크업 관련 게시물에 관심 있는 유저층에 자연스럽게 노출

### 콘텐츠 방향성
1. **공감 → 신뢰 → 전환** 구조를 콘텐츠에 반영
2. 트레이너 본인의 실패 스토리와 성공 경험을 솔직하게 공유
3. 고객 페인포인트를 직접 언급하는 공감형 카피 활용
4. 수강생 Before/After 사례를 통한 사회적 증거 구축

## 성장 로드맵

| 단계 | 목표 |
|------|------|
| 현재 | 1:1 코칭 후기 적극 수집, 초기 신뢰 구축 |
| 단기 | 후기 기반 프로그램 차수 확장 |
| 중기 | 코칭 개월 수 증가, 수강생 커뮤니티 형성 |
| 장기 | 벌크업 전문 브랜드로 포지셔닝, 그룹 프로그램 또는 강의 상품화 |

---

## 운영 원칙

- 수강생 한 명 한 명의 변화를 기록하고 데이터화한다
- 결과보다 과정을 이해시키는 것을 우선한다
- 트레이너가 없어도 수강생이 혼자 실행할 수 있는 상태를 코칭의 성공 기준으로 삼는다
- 콘텐츠는 판매보다 공감을 앞세운다 — 고객이 먼저 다가오게 만든다
