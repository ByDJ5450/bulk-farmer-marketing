# 벌크농부 디자인 스타일 가이드

## 컬러 팔레트

| 역할 | 색상명 | HEX (근사값) | 사용 위치 |
|------|--------|-------------|----------|
| Primary | 세이지 그린 | `#5B9B75` | 배경, 메인 컨테이너 |
| Secondary | 살구 핑크 | `#F2B5A0` | 서브 카드, 강조 박스, 화살표 아이콘 |
| Accent | 레드 | `#E03030` | 핵심 키워드 강조 (벌크업, 확신, 고민 등) |
| Text Primary | 블랙 | `#1A1A1A` | 본문, 제목 |
| Text Light | 화이트 | `#FFFFFF` | 다크 배경 위 텍스트 |
| Sub Text | 살구 핑크 | `#F2B5A0` | 섹션 소제목 (History, Ability, Career) |

## 타이포그래피

### 기본 원칙
- 한국어 본문: **굵은 고딕 계열** (heavy/black weight 우선)
- 영문 레이블: **Bold 산세리프** (Before, After, History 등)
- 장식적 텍스트: 가늘고 우아한 폰트 (혹시..., 만약... 등 감성 카피)

### 위계 구조
| 레벨 | 용도 | 스타일 |
|------|------|--------|
| H1 | 메인 헤드라인 | 최대 크기, Black weight, 줄바꿈 강조 |
| H2 | 섹션 제목 | 중간 크기, Bold, 살구 핑크 또는 블랙 |
| Body | 본문 문장 | 보통~굵음, 줄간격 넉넉하게 |
| Caption | 보조 설명 | 가늘거나 소형 |

## 레이아웃 & 구성 원칙

### 카드/슬라이드 구조
- **1슬라이드 = 1메시지** 원칙: 한 화면에 전달하려는 핵심이 하나여야 함
- 여백을 충분히 두어 텍스트가 숨 쉴 수 있게 구성
- 배경색은 세이지 그린 또는 살구 핑크 두 가지 교체 사용

### 이미지 활용
- 인물 사진: 배경 제거 후 컬러 배경 위에 배치 (자연스러운 합성 느낌)
- 비포/애프터 사진: 나란히 배치, 흰 테두리 또는 그림자 처리
- 원형 크롭: 보조 인물 사진에 사용 (원 마스크 처리)

### 아이콘 & 그래픽
- 체크박스 아이콘: 실패 원인 나열 시 사용 (녹색 체크 이모지 계열)
- 화살표: 살구 핑크 색상의 굵은 화살표 (Before → After 흐름 표현)
- 텍스트 박스: 살구 핑크 배경의 라운드 박스 (핵심 메시지 강조용)

## 콘텐츠 포맷 패턴

### 공감 유도형 (고객 페인포인트 공략)
```
[배경: 세이지 그린]
질문형 헤드라인 (고객 상황 묘사)
↓
트레이너 본인 경험 공감
↓
해결책 또는 변화 가능성 제시
```

### Before / After 비교형
```
[배경: 세이지 그린 + 살구 핑크 박스]
Before 컬럼 | After 컬럼
(부정적 상태) | (긍정적 결과)
```

### 체크리스트형
```
[배경: 살구 핑크]
타이틀 (질문 또는 문제 제시)
✅ 항목 1
✅ 항목 2
✅ 항목 3 ...
```

### 프로필/신뢰 구축형
```
[배경: 세이지 그린]
인물 사진 + 텍스트 나란히 배치
History / Ability / Career 섹션별 정리
```

## 피해야 할 디자인

- 배경색 과다 사용 (2가지 이상의 배경색 혼용)
- 지나치게 작은 텍스트 (모바일 가독성 저하)
- 복잡한 그래프나 인포그래픽 (단순 직관적 구성 우선)
- 화려한 그라데이션 (플랫하고 단색 기반 유지)
