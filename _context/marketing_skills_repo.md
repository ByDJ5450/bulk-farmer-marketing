스킬 하나가 `SKILL.md` + `references/*.md` + `evals/evals.json` 구조다.

설치하면 해당 주제를 꺼낼 때 자동으로 로드된다.


## 안 맞는 것 — 그대로 쓰면 안 된다

| 스킬 | 왜 안 맞나 |
|------|----------|
| **pricing** | SaaS 전용이다. 핵심 개념인 value metric이 "per seat / per usage / per transaction"이다. 170만원 1:1 코칭에 좌석당 과금이 없다 |
| prospecting · ads · aso · paywalls · revops | B2B SaaS·앱 전제 |
| seo-audit · schema | **구글 기준이다.** 한국은 네이버다. hreflang·사이트맵 논의는 우리와 무관 |

**이 레포에 지역 오프라인 사업 내용은 없다.** `local`로 걸리는 건 전부 다국어
현지화(localization)이지 지역 상권 마케팅이 아니다. **군자 문제는 여기서 답이 안 나온다.**

## 지금 우리 일을 바꾸는 것 3가지

### 1. 가치 방정식 — 우리 병목은 "될 것 같다"이다

```
          꿈꾸는 결과  ×  될 것 같다는 믿음
가치  =  ─────────────────────────────────
          걸리는 시간  ×  들어가는 노력
```

벌크농부에 대입하면 이렇다.

| 항목 | 상태 |
|------|------|
| 꿈꾸는 결과 | 높다 — 마른 체형 탈출, 자존감 |
| **될 것 같다는 믿음** | **낮다 ← 병목.** "3년 했는데 내가 되겠나" |
| 걸리는 시간 | 12주로 명시됨. 무난하다 |
| 들어가는 노력 | 높다 — 주 2시간 대면 + 매일 기록 + 5~6끼 |

**우리가 만드는 콘텐츠 대부분이 이미 이 병목을 때리고 있다.** 후기, Before/After,
수치 공개가 전부 "될 것 같다"를 올리는 작업이다. 방향은 맞았다.

가격을 내리는 건 이 표 어디도 못 바꾼다. 가격은 비교 대상이지 가치가 아니다.

### 2. 오퍼 6요소 — 우리에게 **보증이 없다**

| # | 요소 | 벌크농부 |
|---|------|---------|
| 1 | 핵심 제공물 | ✅ 줌 진단 · 강의 · 오프라인 24시간 |
| 2 | 보너스 | ❌ 없음 |
| 3 | **보증** | ❌ **없음 — 가장 큰 구멍** |
| 4 | 희소성 | ✅ 3자리 (실측) |
| 5 | 이름 | ✅ 벌크업 다마고치 프로젝트 |
| 6 | 가격·결제 구조 | △ 170만원. **분납 설계 없음** |

**보증이 병목을 정확히 때린다.** 안 될 것 같아서 못 사는 사람에게
"안 되면 어떻게 되는가"를 답해주는 게 보증이다.

레포가 코칭에 권하는 기본형은 **"첫 2회 안에 아니면 환불"**이다.
결과 보증("12주에 몇 kg 안 늘면 환불")은 권하지 않는다 — 수강생이 안 지켜도
환불 대상이 되고, 마진이 깎이고, 실패 사례가 공개적으로 남는다.

> 우리에게 맞는 형태는 **"첫 2주 안에 방향이 안 맞다고 판단되면 전액 환불"** 쪽이다.
> 이미 줌 진단이 앞에 있어서 2주면 서로 판단이 선다. **결정은 코치 몫이다.**

### 3. 무료 4강은 리드마그넷 기준으로 무겁다

레포 기준: **10분 안에 소비, 하나의 포맷, 즉시 실행 가능.**

우리 무료 4강은 **40분 + 일주일 식사 기록 과제**다. 기준을 한참 넘는다.

두 가지로 볼 수 있다.

- **문제다** — 완주율이 낮아진다. 1강 과제(인바디)에서 대부분 멈춘다
- **문제가 아니다** — 170만원 상품의 앞단이라 거를 사람은 걸러야 한다

**둘 다 맞다. 그래서 앞에 하나를 더 두는 게 맞다.**

레포의 리드마그넷 유형 중 **퀴즈/진단(quiz/assessment — 세분화용)**이 있다.
**우리 1강이 이미 진단이다.** 체지방률과 BMI로 4갈래(다이어트 먼저 / 린매스업 /
벌크업 / 마른 비만)로 나눈다.

```
2분    진단 — 키·몸무게·체지방률 입력 → 내 구간 + 해야 할 것 한 줄
       ↓ 결과를 보려면 회원가입
40분   무료 4강 — 진단 결과에 맞는 순서로
       ↓ 표를 들고
상담   온라인 코칭 / 다마고치
```

**진단이 회원 확보를 하고, 4강이 거른다.** 40분짜리를 첫 관문으로 두는 것보다 낫다.

## 희소성 — 우리가 이미 겪은 사고와 같은 경고

레포가 **"only 3 spots left" 거짓말**을 대표적 금지 패턴으로 든다.
가짜 희소성은 단기 상승 뒤 신뢰가 무너진다고 못 박는다.

> 2026-08-04 모집공고 초안에 "동시 3명까지만 받습니다 / 2자리 남았습니다"라고
> 썼다가 지웠다. 근거 없이 만든 숫자였다. 지금 공고의 "3자리"는 실측이다.

**정직한 희소성 형태로 레포가 인정하는 것**: 정원 기반, 기수 기반, 창립 멤버 가격,
가격 인상 예고, 보너스 만료. 우리는 정원 기반이고 근거가 있다. 이대로 간다.
