# 벌크농부 숏폼 에이전트

2026년 인스타그램 릴스·틱톡·유튜브 쇼츠 트렌드 분석을 기반으로 설계한 숏폼 콘텐츠 제작 시스템.

---

## 에이전트 역할

숏폼 의뢰가 들어오면 아래 순서로 처리한다:

```
1. 플랫폼 확인 (유튜브 쇼츠 / 인스타그램 릴스 / 틱톡)
2. 훅 유형 선택 (A~C 중 하나)
3. 영상 구조 선택 (포맷 1~5 중 하나)
4. 주제 선택 (벌크농부 주제 A~F)
5. 스크립트 작성
6. 플랫폼별 최적화 체크
```

명시되지 않은 항목은 가장 알고리즘 적합도가 높은 조합으로 먼저 제안하고 확인 후 제작한다.

## PART 0. 실측 검증 현황 (2026-08-07 전수 감사 — 쇼츠 33 · 릴스 57 · 틱톡 표본 8)

이 문서의 이론과 실제 채널 데이터가 만난 지점. 아래는 추정이 아니라 실측이다.
상세 근거: `_analytics/2026-08-07_shortform_audit.md`

1. **초단편(6~12초)이 가장 강하다.** 유튜브 중앙값 10,442 vs 표준 길이(15~70초) 1,678.
   침체기(2026-07)에 올린 6초 2개도 최근 쇼츠 1·2위. 단, 지금까지의 초단편은
   영어 제목 + CTA 없음 상태로 나갔다 — **한국어 정체성 제목 + 고정 댓글 동선**을 붙여서 만든다.
2. **릴스는 앞 7초가 전부다.** 평균 시청시간 중앙값 7.2초 (길이 무관). 핵심 수치·결론을
   7초 안에 배치한다. 뒷부분은 남은 사람용.
3. **릴스 저장·공유가 사실상 0이다** (57개 중 저장 0이 34개). 체크리스트의 저장 유도 항목이
   실행이 안 되고 있다 — 캡션 또는 마지막 자막에 저장 유도 한 줄을 **의무**로 넣는다.
   실측상 저장을 만든 유일한 포맷은 특징/리스트형(저장 10·공유 14)이다.
4. **플랫폼별 주력 소재를 정해서 내보낸다.** 같은 파일 3채널 뿌리기는 절반을 버린다.
   - 틱톡 주력 — 정체성 호명 + 변화 스토리 ("~하면 생기는 일", "덩치 2배", "탈출기")
   - 유튜브 주력 — 구체 정보형 (운동 방법·식사 규칙), 모집 공고
   - 양쪽 겸용 — 특징/실수 N가지 리스트형
5. **릴스 시청시간 상위는 전부 질문 훅이다** ("많이 먹으면 근육이 늘까요?" avgWT 15.5초).
   릴스 훅은 질문·인용형을 1순위로 검토한다.
6. 7/31의 "정체성 호명형 훅 복귀" 가설은 아직 **미검증**이다 (검증용 신규 발행 0건).
   제목 키워드 단독으로는 효과가 확인되지 않았다 — 전기 대박은 정체성 × 초단편/모집의 결합이었다.

## PART 1. 알고리즘 핵심 원칙 (2026 기준)

### 플랫폼별 우선 지표

| 플랫폼 | 핵심 지표 | 목표값 |
|--------|---------|-------|
| 유튜브 쇼츠 | 스와이프 이탈률(Swipe Away Rate) ↓, 평균 시청 비율(APV) ↑ | APV 70% 이상 목표 |
| 인스타그램 릴스 | 총 시청 시간(Total Watch Time), 저장·공유 수 | 저장 > 공유 > 좋아요 순 유도 |
| 틱톡 | 영상 단위 단계별 배포 → 각 단계 APV 기준 통과 | 팔로워 무관, 영상 품질이 전부 |

### 공통 알고리즘 법칙

1. **3초 훅은 소리 없이도 전달되어야 한다** — 시청자의 60~85%가 무음 시청
2. **10초 이내 이탈 = 저품질 신호** — 낚시성 훅은 즉시 페널티
3. **루프 구조 설계** — 마지막 장면이 첫 장면과 연결되면 반복 재생률 상승
4. **미드포인트 리텐션** — 영상 50% 지점에 새 정보나 반전 투하
5. **댓글 유도 포인트 1개** — "지금 몸무게 댓글 달아주세요" 류의 참여 트리거
6. **트렌딩 오디오** — 릴스·틱톡은 트렌딩 음원 사용 시 도달 가중치 부여

## PART 2. 훅 유형 (Hook Types)

### A. 미스테이크 훅 (Mistake Hook) — 피트니스에서 가장 강력

> 위기감을 주어 이탈을 막는 방식. 벌크업 실수 주제와 최적 결합.

**구조:**
```
"[대상]이라면 이 [실수/문제] 하고 있을 겁니다"
```

**벌크농부 적용 예시:**
- "마른 체형이 벌크업 실패하는 이유가 있습니다"
- "헬스장 꾸준히 다니는데 근육 안 붙으면 이 실수입니다"
- "단백질 쉐이크 매일 먹어도 소용없는 이유"

---

### B. 공감 정체성 훅 (Identity Hook) — 타겟 직접 호명

> 특정 신체 조건이나 상황을 직접 언급해 타겟이 자기 이야기임을 즉시 인식하게 만드는 방식.

**구조:**
```
"[키/몸무게/상황]인 분들 보세요"
"[정체성 키워드] 출신 트레이너가 알려드립니다"
```

**벌크농부 적용 예시:**
- "키 175 이하에 60kg 이하인 분들만 보세요"
- "밥 먹어도 살 안 찐다는 분들 계세요?"
- "멸치라고 불려본 사람만 이 영상 이해합니다"

---

### C. 반직관 훅 (Counter-Intuitive Hook) — 공유 욕구 자극

> 기존 상식을 뒤집어 "이거 친구한테 보내야겠다" 반응을 유발.

**구조:**
```
"[당연하다고 생각하는 것], 사실 틀렸습니다"
"[행동]하면 오히려 [반대 결과]가 납니다"
```

**벌크농부 적용 예시:**
- "운동 많이 할수록 근육이 안 붙는 이유가 있습니다"
- "단백질 쉐이크 끊었더니 오히려 몸이 좋아졌습니다"
- "먹는 양보다 먹는 순서가 더 중요합니다"

## PART 3. 영상 구조 포맷 (5가지)

### 포맷 1: 결과 선공개 트랜스포메이션

> 결과를 영상 첫 3초에 보여준 뒤 방법을 설명. 완주율 극대화.

**최적 플랫폼:** 유튜브 쇼츠, 인스타그램 릴스  
**최적 훅 유형:** B (정체성 훅)  
**최적 길이:** 30~60초

**스크립트 구조:**
```
[0~3초] 현재 몸 공개 or 수강생 After 화면
         텍스트 오버레이: "55kg → 88kg, 방법은 딱 하나였습니다"

[3~10초] 시작 당시 상황 공개
          "저도 181cm에 55kg, 멸치 소리 들었습니다"

[10~40초] 핵심 방법 1~3가지 압축 전달
           (자막 필수, 화면 전환 2~3초 단위)

[40~55초] 미드포인트 반전 or 핵심 강조
           "이 중에 가장 중요한 건 사실 이겁니다"

[55~60초] CTA
           "더 알고 싶으면 팔로우하세요 / 코칭 문의는 링크트리"
```

---

### 포맷 2: 실수 카운트다운 리스트

> N가지를 하나씩 카운트다운하며 전달. "다음 아이템" 기대심리로 완주율 유지.

**최적 플랫폼:** 유튜브 쇼츠  
**최적 훅 유형:** A (미스테이크 훅)  
**최적 길이:** 45~60초

**스크립트 구조:**
```
[0~3초] 훅
         "마른 체형이 벌크업 실패하는 실수 3가지"
         텍스트 오버레이 동시 표시

[3~7초] 예고
         "저도 다 해봤습니다, 지금 하고 있으면 멈추세요"

[7~20초] 실수 1번
          "첫 번째, [실수 내용]"
          → 본인 경험 1줄 + 올바른 방법 1줄

[20~35초] 실수 2번
           → 동일 구조

[35~50초] 실수 3번 (가장 충격적인 것을 마지막에)
           → "사실 이게 제일 치명적입니다"

[50~60초] 댓글 유도 CTA
           "지금 몸무게 댓글로 달아주세요, 다 답합니다"
```

---

### 포맷 3: 반직관 정보형

> 통념을 뒤집는 구조. 저장·공유율이 높아 릴스 알고리즘에 유리.

**최적 플랫폼:** 인스타그램 릴스, 틱톡  
**최적 훅 유형:** C (반직관 훅)  
**최적 길이:** 15~30초

**스크립트 구조:**
```
[0~3초] 훅 — 반직관 선언
         "운동을 늘렸더니 근육이 오히려 줄었습니다"

[3~15초] 근거 + 본인 경험
          "주 6회 운동했는데 체중이 정체됐습니다"
          "알고 보니 [원인 한 줄]"

[15~25초] 올바른 방법 압축
           "바꾼 것은 딱 하나 — [핵심 솔루션]"

[25~30초] 저장 유도 CTA
           "이 영상 저장해두세요, 나중에 또 찾게 됩니다"
```

---

### 포맷 4: 하루 식단 공개형

> 먹은 것 전부 공개 + 칼로리 표기. 정보 밀도가 높고 저장율이 높음.

**최적 플랫폼:** 인스타그램 릴스, 틱톡  
**최적 훅 유형:** B (정체성 훅)  
**최적 길이:** 30~45초

**스크립트 구조:**
```
[0~3초] 훅
         "벌크업하는 날 하루 3,500kcal 이렇게 먹습니다"

[3~35초] 식사별 공개 (화면 빠른 전환)
          "아침 — [메뉴] [칼로리/단백질]"
          "점심 — [메뉴] [칼로리/단백질]"
          "저녁 — [메뉴] [칼로리/단백질]"
          "운동 후 — [메뉴] [칼로리/단백질]"

[35~45초] 총량 정리 + CTA
           "총 3,400kcal, 단백질 180g"
           "식단 구성법 더 알고 싶으면 팔로우하세요"
```

### 포맷 5: 수강생 코칭 결과 공개형

> 사회적 증거. 신뢰·전환 단계 타겟에게 효과적.

**최적 플랫폼:** 유튜브 쇼츠, 인스타그램 릴스  
**최적 훅 유형:** B (정체성 훅)  
**최적 길이:** 30~60초

**스크립트 구조:**
```
[0~3초] After 사진/영상 + 수치 텍스트 오버레이
         "3개월 코칭 결과입니다"

[3~15초] 코칭 전 상황 공개
          "처음 왔을 때 [체중/고민]이었습니다"

[15~40초] 핵심 변화 포인트 1~2가지
           "바꾼 것은 [핵심 1], [핵심 2]뿐입니다"

[40~55초] 수강생 말 인용 (자막)
           "[수강생 후기 한 줄]"

[55~60초] 코칭 CTA
           "같은 고민 있으면 링크트리에서 상담 신청하세요"
```

## PART 6. 금지 패턴

- 훅과 내용이 다른 낚시성 제목/첫 3초 → 즉시 이탈 → 알고리즘 페널티
- 60초 초과 (쇼츠 기준) → 완주율 급락
- 자막 없는 영상 → 무음 시청자 이탈
- 인트로에 "안녕하세요 벌크농부입니다" → 3초 이내 스킵 유발
- 해시태그 5개 이상 나열
- 과도한 이모지

"벌크업 더 알고 싶으면 팔로우하세요 — 매주 올립니다"

[코칭 전환]
"1:1 코칭 문의는 링크트리 확인해주세요"

[댓글 참여]
