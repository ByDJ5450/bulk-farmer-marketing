## 업로드 체크리스트 (개당 2~3분)

1. `_reels/{슬러그}/reel.mp4` 업로드 (유튜브 쇼츠·틱톡·인스타 릴스)
2. caption.txt 위쪽 = 캡션, 아래쪽 = **고정 댓글** (업로드 직후 달기)
3. 인스타 릴스만: 커버는 cover.jpg, 트렌딩 오디오 낮은 볼륨으로 추가
4. 유튜브 제목은 caption 첫 줄 사용 (한국어 정체성형 유지)

## 편집 사양 최종 (2026-08-13 — 24개 전체 적용 완료)

레퍼런스 해부(`_org/insights/2026-08-13_제보.md`) 반영. 전 편에 들어간 것:

| 옵션 | 값 | 효과 |
|---|---|---|
| `xfade: 0.25` | 세그먼트 경계 | 디졸브 + 오디오 크로스페이드 — 점프컷·룸톤 단절 제거 |
| `zoom: 1.0↔1.07` | 세그먼트 교대 | 펀치인 리듬 (컷 대체). 무음 경계가 있는 곳만 쪼갠다 — 24개 중 14개 적용, 10개는 경계가 없어 원테이크 유지 |
| `outro_fade: 0.4` | 마지막 | 정지 프레임 0.45초 + 페이드아웃 끝맺음 |
| `hold: 0.25~0.35` | 말 꼬리가 빡빡한 세그먼트 끝 | 정지 프레임+무음 패드 — 말이 온전히 끝난 뒤 정지 화면 위에서 디졸브. 원본에서 다음 문장이 쉼 없이 붙어 오는 컷에 쓴다 (2026-08-14, 6곳 적용) |
| `panel` | **미적용** | 유튜브 컷 기반에는 뺀다 (2026-08-13 사용자 지시). 신규 제작 릴스용 |
| `bgm` | 보류 | 트랙 미정. IG·틱톡은 앱 음원, 유튜브용 파일에만 구울 것 |

### 문장 경계 검증 (2026-08-14 — 24개 전체 통과)

유튜브 자동 자막(단어 타임스탬프)으로 24개 전 세그먼트 경계를 대조해,
문장 중간에서 끊기던 경계 42곳을 문장 단위로 재조정하고 21개를 재조립했다.
모든 세그먼트가 문장 시작에서 열리고 문장 끝에서 닫히며, 세그먼트 사이 내용 흐름도 점검 완료.
검증 도구: 스크래치패드 `fix_boundaries.py` (자막 단어 시각 → 무음 구간 스냅 → 재조립).
새 숏폼을 만들 때도 **컷 경계는 자막 단어 타임스탬프로 문장 경계를 확인**하고 자른다.

## 수정하고 싶을 때

`spec_{슬러그}.json`에서 자막 문구(`lines`)·타이밍(`t`)·컷 구간(`start`/`dur`)을 고친 뒤:

```bash
python3 _reels/build_reel.py _reels/spec_{슬러그}.json
```

원본 영상 경로가 임시폴더(`/private/tmp/...scratchpad/src/`)라 맥 재부팅 후에는
yt-dlp로 다시 받아 스펙의 src 경로만 바꾸면 된다.
