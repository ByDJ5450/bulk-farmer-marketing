# 멸치 탈출 벌크업 스타터 가이드

> 55kg 멸치에서 88kg까지 — 벌크업, 오늘 방향부터 잡아드립니다.
> 벌크농부

---

## 0. 시작하기 전에 — 제 이야기를 먼저 하겠습니다

181cm에 55kg.
별명은 '멸치'였습니다.

거울을 볼 때마다 자신이 없었고, 승무원이라는 꿈도 "마른 사람이라 안 돼"라는 말에 포기했습니다.

무작정 헬스장에 등록했지만 1년 가까이 체중은 그대로였습니다.
운동만 열심히 하면 되는 줄 알았으니까요.

그때부터 하나씩 공부했습니다.
왜 몸이 커지는지, 뭘 먹어야 하는지, 어떤 운동이 필요한지.

원리를 이해하고 나서 2년, 저는 88kg이 됐고 K-Classic 클래식 피지크 대회에서 3위에 올랐습니다.

타고난 몸은 없습니다.
이 가이드는 제가 55kg 시절의 저에게 쥐여주고 싶었던, 딱 그 내용입니다.

---

## 1. 벌크업이 안 되는 진짜 이유 3가지

1년을 운동해도 몸이 안 변했다면, 체질이 아니라 아래 셋 중 하나입니다.

**① 생각보다 훨씬 적게 먹고 있다**
"저는 많이 먹는데요?"라고 말하는 분들의 실제 섭취량을 기록해보면 대부분 하루 필요량보다 500~1,000kcal 부족합니다. 느낌이 아니라 숫자로 확인해야 합니다.

**② 운동이 자극이 아니라 소모로 끝난다**
머신 10가지를 도는 것보다 바벨 복합 운동 몇 가지에 집중하는 것이 근육에는 훨씬 강한 성장 신호입니다. 운동은 '자극', 식단은 '재료' — 둘 다 필수입니다.

**③ 기록하지 않는다**
지난주보다 무게가 올랐는지, 체중이 늘고 있는지 모르면 방향 없이 걷는 것과 같습니다. 기록 없는 노력은 쌓이지 않습니다.

## 2. 내 하루 목표 칼로리 계산하기 (3단계)

벌크업의 출발점은 운동이 아니라 이 숫자입니다.

**1단계 — 기초대사량(BMR)**
```
체중(kg) × 24 = BMR
예) 60kg × 24 = 1,440kcal
```

**2단계 — 하루 총 소비량(TDEE)**
```
BMR × 활동 계수
- × 1.2    운동을 거의 안 함 (좌식 생활)
- × 1.375  가벼운 운동 주 1~3회
- × 1.55   보통 강도 운동 주 3~5회
- × 1.725  고강도 운동 주 6~7회
- × 1.9    육체노동 + 매일 운동
예) 1,440 × 1.55 = 약 2,230kcal
```

**3단계 — 벌크업 목표 칼로리**
```
TDEE + 300~500kcal (칼로리 잉여)
예) 2,230 + 400 = 약 2,630kcal
```

여기에 단백질은 **하루 총량 기준 체중×1.6~2.2g**을 확보하세요.
(예: 60kg → 하루 96g 이상. 섭취 타이밍보다 하루 총량이 훨씬 중요합니다.)

> ✍️ 지금 계산해서 적어두세요: 내 목표 칼로리 ______ kcal / 내 목표 단백질 ______ g

## 3. 하루 식단 템플릿

계산한 목표 칼로리를 채우는 게 처음엔 막막합니다. 아래 템플릿에서 시작해 양을 조절하세요.

**기본형 (약 2,600kcal / 단백질 약 130g)**

| 끼니 | 구성 |
|------|------|
| 아침 | 프로틴 그래놀라 + 우유 300ml + 바나나 1개 (유당불내증이 있다면 락토프리 우유로) |
| 점심 | 일반식이면 충분 — 제육덮밥, 불고기백반 등 고기 반찬 + 밥 1.5공기 |
| 간식 | 그릭요거트 + 견과류 또는 달걀 2개 + 고구마 1개 |
| 저녁 | 밥 1공기 + 고기 또는 생선 150g + 채소 (외식이라면 고기 위주 메뉴 선택) |
| 취침 전 | 우유 300ml 또는 그릭요거트 |

매 끼니가 닭가슴살일 필요 없습니다.
**일반식에서 밥과 고기 반찬을 늘리는 것**, 그게 벌크업 식단의 시작입니다.

**저예산형 (약 2,500kcal / 식비 최소화)**

| 끼니 | 구성 |
|------|------|
| 아침 | 그래놀라 또는 귀리 60g + 두유 400ml + 바나나 1개 |
| 점심 | 밥 1.5공기 + 달걀 4개 + 김치 (학식·백반집 일반식도 충분) |
| 간식 | 고구마 2개 + 두유 200ml |
| 저녁 | 밥 1공기 + 닭가슴살 또는 두부 200g + 채소 |

포인트는 완벽한 식단이 아니라 **매일 목표 칼로리를 채우는 것**입니다.
보충제는 식사로 부족할 때 채우는 보조 수단입니다. 필수가 아닙니다.

## 4. 운동은 7가지면 충분합니다

벌크업에 필요한 운동은 생각보다 적습니다. 아래 7가지가 전부입니다.

1. 벤치프레스
2. 스쿼트
3. 데드리프트
4. 바벨로우
5. OHP (오버헤드프레스)
6. 풀업
7. 딥스

**초보자 추천 루틴 — 주 4회 상하 분할**

| 요일 | 부위 | 운동 |
|------|------|------|
| 월 | 상체 | 벤치프레스 / 바벨로우 / OHP |
| 화 | 하체 | 스쿼트 / 데드리프트 |
| 목 | 상체 | 벤치프레스 / 풀업 / 딥스 |
| 금 | 하체 | 스쿼트 / 데드리프트 |

- 각 운동 3~4세트, 6~12회 범위
- 지난주보다 무게 또는 횟수를 조금씩 올리는 것(점진적 과부하)이 핵심
- 같은 부위는 48시간 회복 후 다시 자극

## 5. 첫 4주 체크리스트

매일 아래 4개만 지키면 됩니다. 완벽할 필요 없습니다.

- [ ] 목표 칼로리 ±200kcal 안에서 먹었다
- [ ] 단백질 하루 총량을 채웠다
- [ ] 운동한 날: 운동명 + 무게 + 세트×횟수를 기록했다
- [ ] 아침 공복 체중을 기록했다 (주간 평균으로 판단)

**4주 뒤 확인할 것**
- 체중 주간 평균이 +0.5~1kg 움직였는가
- 주요 운동 무게나 횟수가 올랐는가

둘 중 하나라도 움직였다면, 방향이 맞는 겁니다. 그대로 가면 됩니다.
