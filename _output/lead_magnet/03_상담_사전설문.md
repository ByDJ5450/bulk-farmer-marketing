# 무료 전략 상담 — 사전 설문

작성일: 2026-07-16
용도: 구글폼 또는 카카오톡 채널 상담 신청 시 필수 입력
목적: ① 진성 고객 필터링 ② 상담 전에 진단 데이터 확보 ③ 신청자가 자기 상황을 스스로 정리하게 만들기

---

## 설문 안내문 (폼 상단에 그대로 사용)

> **무료 전략 상담 신청 전, 3분만 내주세요.**
>
> 아래 답변을 바탕으로 상담 전에 회원님의 상태를 미리 분석해갑니다.
> 자세히 적어주실수록 상담에서 받아가는 게 많아집니다.
>
> 상담은 30~40분, 결제 권유 없이 진단만 받고 가셔도 됩니다.

---

## 설문 문항 (10개)

**1. 성함 또는 닉네임** (단답)

**2. 나이대** (객관식)
- 20대 초반 / 20대 중후반 / 30대 / 40대 이상

**3. 키와 현재 몸무게** (단답)
- 예: 178cm / 58kg

**4. 3개월 뒤, 어떤 몸이 되고 싶으세요?** (주관식)
- 숫자든 이미지든 자유롭게 적어주세요. 예: "65kg", "옷태가 사는 몸", "여름에 반팔이 부끄럽지 않게"

**5. 운동 경력** (객관식 + 단답)
- 없음 / 6개월 미만 / 6개월~2년 / 2년 이상
- 현재 주 몇 회 운동하시나요?

**6. 어제 하루 드신 것을 그대로 적어주세요** (주관식) ★핵심 문항
- 아침 / 점심 / 저녁 / 간식 순서로, 기억나는 대로 전부.
- "잘 먹은 날"이 아니라 "평범한 어제"를 적어주셔야 정확한 진단이 됩니다.

**7. 벌크업을 위해 지금까지 시도해본 것** (복수 선택)
- PT / 유튜브 독학 / 보충제 / 식단 앱 / 헬스장 등록만 / 기타( )

**8. 그런데 왜 안 됐다고 생각하세요?** (주관식) ★핵심 문항
- 본인이 생각하는 이유를 솔직하게 적어주세요.

**9. 운동에 쓸 수 있는 시간** (단답)
- 가능한 요일과 시간대. 예: "평일 퇴근 후 8시 이후, 주말 오전"

**10. 코칭을 받는다면 가장 도움받고 싶은 부분** (객관식) + 상담 희망 시간대 (단답)
- 식단 구성 / 운동 루틴 / 꾸준함(습관) / 전부 다

---

## 설계 의도 (내부 참고용)

| 문항 | 상담에서의 활용 |
|------|--------------|
| 3 + 6 | **TDEE 계산 + 실제 섭취량 추정 → 갭을 kcal 숫자로 제시** (진단의 핵심 무기) |
| 4 | 상담 클로징 때 본인이 쓴 목표를 그대로 다시 읽어줌 — "이 목표, 3개월이면 됩니다" |
| 7 + 8 | 실패 원인을 본인 입으로 말하게 함 → 상담에서 "그건 회원님 탓이 아니라 방법 문제" 프레임 전환 |
| 6 성실도 | 대충 쓴 신청자 = 진성도 낮음 → 상담 우선순위 조정 기준 |
| 9 | 코칭 제안 시 맞춤 루틴 예시를 즉석에서 제시할 재료 |

**필터링 기준:** 6번·8번을 한 줄 이하로 대충 쓴 경우, 상담 전 카카오톡으로 한 번 더 구체화 요청 → 응답 없으면 후순위.
