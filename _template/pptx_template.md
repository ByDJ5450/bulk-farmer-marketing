# 벌크농부 PPT 템플릿 가이드

> PPTX.pptx (42슬라이드, 벌크업 홀로서기 Basic 과정 1주차) 기반으로 작성된 템플릿 참조 문서.  
> 새 PPT 제작 시 아래 레이아웃 패턴과 디자인 규격을 그대로 활용한다.

## 3. 레이아웃 패턴 (8종)

### 패턴 A — 커버 슬라이드 (슬라이드 1)
```
[배경: 흰색 + 우측 인물/이미지 합성]

좌측 (left ~8%, top ~33%, w ~49%)
  메인 타이틀 (65pt, Bold, #000)
  3줄 이내

하단 좌측 (left ~6%, top ~87%, w ~60%)
  서브타이틀 / 과정명 (42pt, Bold, #000)
```
**사용 예:** "지속 가능한 / 벌크업 성공을 위해 / 꼭 알아야 하는 기초 이론"

---

### 패턴 B — 좌우 분할 리스트 슬라이드 (슬라이드 2, 3, 9, 29, 38, 39, 41, 42)
```
[배경: 흰색 + 좌측 인물 이미지]

좌측 타이틀 블록 (left ~1-10%, top ~37-45%, w ~30%)
  메인 키워드 (48~50pt, Bold)
  2~3줄

우측 리스트 블록 (left ~41-49%, top ~30%, w ~42-57%)
  항목 1 (30pt, Bold) — top ~30%
  항목 2 (30pt, Bold) — top ~47%
  항목 3 (30pt, Bold) — top ~61%  ← 3항목이 표준
```
**사용 예:** 타겟 대상 나열 / 주차 커리큘럼 소개 / 오해 3가지 / 숙제 목록

---

### 패턴 C — 이유·문제·해결 3슬라이드 세트 (슬라이드 12~14, 24~26, 30~32)
```
반복 사용되는 3연속 구조:

[슬라이드 ①: 이유/문제]
  좌 (left ~1%, top ~32-40%, w ~33%)
    "이유 N :" + 핵심 문제명 (50pt, Bold)
  우 (left ~34-48%, top ~32~61%)
    증거/현상 3가지 (30~35pt, Light 또는 Bold)

[슬라이드 ②: 발생 원인]
  좌 "이런 문제가 / 발생하는 / 이유" (50pt, Bold)
  우 원인 3가지 (Light)

[슬라이드 ③: 해결 시 이점]
  좌 "이런 실수를 / 멈추신다면..!" (50pt, Bold)
  우 달라지는 점 3가지 (Light)
```
**적용 챕터:** 이유1(근육 원리), 이유2(체형 분석), 잘못된 상식 1~3

---

### 패턴 D — 챕터 인트로 슬라이드 (슬라이드 11, 28, 33, 37)

```

### 패턴 E — 포인트 배경 교육 슬라이드 (슬라이드 18~23, 27, 34, 36, 40)

중간 소제목 (left ~6%, top ~33%, w ~48%)

**사용 예:** 벌크업의 핵심원리 / 자신의 현재 체형 분석 / 실제 사례 / 벌크농부의 마인드 세팅

### 패턴 F — 개념 정의 임팩트 슬라이드 (슬라이드 15~17)

### 패턴 G — 3열 약속/혜택 슬라이드 (슬라이드 10)
```

  "다음을 약속드립니다" (50pt, Bold, #1D1D1F)

  각 열 상단: 숫자 1/2/3 (50pt, Bold, #3D3D3D) — top ~49%

## 5. 반복 구조 공식 (콘텐츠 제작 시 참고)

### 문제 챕터 3슬라이드 공식
```
[슬라이드 ①] 이유 N : [문제명]
  우측 → 이 문제로 나타나는 현상 3가지 (Light)

[슬라이드 ②] 이런 문제가 / 발생하는 / 이유
  우측 → 그렇게 생각하는 잘못된 믿음 3가지 (Light)

[슬라이드 ③] 이런 실수를 / 멈추신다면..!
  우측 → 바꿨을 때 달라지는 점 3가지 (Light)
```

### 핵심원리 교육 슬라이드 공식 (패턴 E)
```
[전폭 헤더] 섹션 제목 (100pt)
[소제목] 이번 슬라이드의 소주제 (60pt)
[본문] 설명 텍스트, 줄바꿈 활용 (40pt Light)
       → 핵심 단어/구에 레드 #FF3131 인라인 강조 가능
```

### 포인트 슬라이드 오프닝 공식 (패턴 D)
```
좌측 절반 = 인물 이미지 (배경 제거)
우측 = 챕터 제목 (50pt, Bold, 2~4줄)
       → 다음에 이어질 3~6개 슬라이드의 주제를 하나의 문장으로 압축
```

## 6. 피해야 할 패턴

- 한 슬라이드에 4개 이상의 텍스트 블록 혼용
- Light 폰트와 Bold 폰트를 같은 크기로 나란히 쓰는 것 (위계 혼란)
- 포인트 배경(#66AA85)에서 레드(#FF3131) 강조 남발 (1~2 단어 이내로 제한)
- 3항목 리스트를 4~5항목으로 늘리는 것 (가독성 저하)
- 챕터 인트로(패턴 D) 없이 바로 교육 슬라이드로 넘어가는 것
