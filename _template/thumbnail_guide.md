# 벌크농부 유튜브 썸네일 제작 가이드

> 기준: thumbnail_01~04.jpg 분석 결과  
> 모든 썸네일은 **16:9 비율** 고정

---

## 1. 레이아웃 유형 (4가지)

| 유형 | 구성 | 사용 상황 |
|------|------|---------|
| **A. 인물 단독형** | 전신/상반신 사진 + 상단 태그 + 하단 메인 텍스트 | 공감형, 스토리형 영상 |
| **B. Before/After형** | 좌(Before 사진) → 빨간 화살표 → 우(After 사진) + 하단 텍스트 | 변화 결과, 중간점검 영상 |
| **C. 상황 몰입형** | 일상 공간(방, 거리 등) 배경 + 상단 텍스트 오버레이 | 공감·현실 묘사 영상 |
| **D. 액션 현장형** | 운동/훈련 중 장면 + 상단 태그 박스 + 하단 텍스트 | 운동 루틴, 방법 소개 영상 |

---

## 2. 텍스트 배치 원칙

```
[상단 영역]
  - 태그/라벨: 우측 상단 또는 좌측 상단
  - 포맷: 둥근 모서리 박스 (흰색 or 검정 배경) + 굵은 텍스트
  - 예: "35살 마른 남자", "2탄", "실제로 한 사람", "2차 중간점검"

[중앙 영역]
  - 빨간 화살표로 인물 지목 (인물 단독형, 액션 현장형)
  - Before/After형에서는 중앙에 → 화살표 배치

[하단 영역]
  - 핵심 메시지 (가장 큰 텍스트)
  - 폰트: Heavy/Black weight 고딕, 흰색 + 두꺼운 검정 아웃라인
  - 숫자/키워드: 노란색(Yellow) 강조
```

---

## 3. 컬러 시스템

| 요소 | 색상 | 용도 |
|------|------|------|
| 메인 텍스트 | `#FFFFFF` (흰색) + 검정 아웃라인 | 모든 핵심 텍스트 |
| 강조 숫자/키워드 | 노란색 (Yellow) | 수치(kg, 주 수), 핵심 단어 |
| 화살표 | `#E03030` (레드) | 인물 지목, Before→After 연결 |
| 태그 박스 배경 | `#1A1A1A` (검정) or `#FFFFFF` (흰색) | 상단 라벨 |
| 배경 포인트 | 세이지 그린 `#5B9B75` / 살구 핑크 `#F2B5A0` | 배경 단색 처리 시 선택 사용 |

---

## 4. 화살표 규칙

- **두께:** 매우 굵게 (stroke width 크게)
- **색상:** 빨간색(`#E03030`) + 흰색 테두리
- **방향:**
  - 인물 지목 시: 대각선으로 인물 머리/몸 방향
  - Before/After 연결 시: 수평 →
- **크기:** 썸네일 높이의 25~35% 수준으로 눈에 띄게

---

## 5. 회차/시리즈 표시

- 위치: 우측 상단
- 포맷: `N탄` or `N차 중간점검` — 둥근 박스 or 텍스트 단독
- 색상: 흰색 텍스트 + 검정 배경 박스

---

## 6. 영상 유형별 썸네일 공식

### 수강생 중간점검 / 결과 영상
```
[구성] Before/After형 (B유형)
[상단] 우측 상단 — "N차 중간점검" 또는 "N탄" 배지
[중앙] 좌(입회 당시 사진) → 빨간 화살표 → 우(현재 사진)
[하단] "N주 만에 [숫자]kg 쪘습니다" — 숫자는 노란색 강조
[포인트] 수치를 반드시 노출 — 클릭률 핵심 요소
```

### 공감·스토리 영상
```
[구성] 인물 단독형 (A유형) 또는 상황 몰입형 (C유형)
[상단] 인물 특징 라벨 ("35살 마른 남자", "키 181cm 멸치" 등)
[중앙] 빨간 화살표로 인물 지목
[하단] 감정 자극 문장 ("이제는 정말 바꾸고 싶어요" 등)
[포인트] 인물 표정: 진지/고민 or 결의 표정 선택
```

### 운동/방법 소개 영상
```
[구성] 액션 현장형 (D유형)
[상단] "실제로 한 사람" 등 신뢰 라벨 + 빨간 화살표
[하단] "N주 만에 Nkg 벌크업 하는 운동 루틴" — 숫자 노란색
[포인트] 운동 동작 중 포착 장면 사용
```

---

## 7. 제작 시 체크리스트

- [ ] 16:9 비율 확인
- [ ] 메인 텍스트가 모바일에서도 읽히는 크기인가
- [ ] 숫자/핵심 키워드 노란색 강조 적용
- [ ] 화살표 빨간색, 두께 충분한가
- [ ] 상단 태그 박스 있는가 (시리즈물의 경우 회차 표시)
- [ ] 인물 사진 밝기/대비 충분한가 (어두우면 텍스트와 구분 안 됨)
