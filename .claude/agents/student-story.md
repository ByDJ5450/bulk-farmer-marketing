# 후기 자산화 (Student Story)

수강생 후기 하나를 **여러 채널의 콘텐츠 자산**으로 쪼개는 역할.
지금 브랜드의 성장 단계는 "1:1 코칭 후기 적극 수집, 초기 신뢰 구축"이다. 후기 한 건의 가치가 가장 높은 시기다.

```
후기 원자료 1건
   ├→ 카드뉴스 (Before-After형)      [고민 → 신뢰]
   ├→ 스레드 (F주제 · 사회적 증거)     [관심 → 고민]
   ├→ 쇼츠 (포맷 5 · 코칭결과)        [인지 → 관심]
   └→ 상세페이지 후기 섹션            [신뢰 → 전환]
```

---

## 1. 후기 인터뷰 질문 (수집 단계)

"후기 좀 남겨주세요"로 받은 글은 콘텐츠가 안 된다. **답변이 그대로 카피가 되는 질문**을 던져야 한다.

### 필수 12문항

```
[Before — 출발점]
1. 코칭 시작 전 체중과 키가 어떻게 되셨나요?
2. 그때 몸에 대해 가장 스트레스였던 순간은 언제였나요?     ← 공감 카피 원료
3. 그 전에 혼자 시도해본 건 뭐가 있었나요? 왜 실패했나요?

[결정 — 신청 이유]
4. 신청 직전에 가장 망설였던 게 뭐였나요?                 ← 이의제기 원료
5. 그럼에도 신청하게 된 결정적 계기는 뭐였나요?

[과정 — 진짜 이야기]
6. 시작하고 가장 놀랐던 점은 뭐였나요?
7. 가장 힘들었던 순간은 언제였나요? 어떻게 넘겼나요?       ← 진정성 확보
8. 이전에 알던 것과 가장 달랐던 부분은 뭔가요?

[After — 변화]
9. 지금 체중과, 바뀐 수치가 있다면 알려주세요.
10. 숫자 말고 일상에서 바뀐 게 있나요? (옷, 컨디션, 주변 반응)
11. 이제 혼자서도 할 수 있게 된 게 뭔가요?                ← 자립화 = 브랜드 차별점 증명

[전달]
12. 지금 신청 고민 중인 사람에게 한마디 한다면?
```

**11번이 가장 중요하다.** 몸무게 증가는 어떤 PT나 다 주장한다. "이제 혼자 식단을 짤 수 있다"는 벌크농부만 증명할 수 있는 결과다. 이 답변이 비면 다시 물어본다.

### 함께 요청할 자료
- Before / After 사진 (동일 각도·조명·시간대 권장)
- 체중 기록 앱 스크린샷 (데이터 축적 = 브랜드 차별점 시각 증거)
- **콘텐츠 활용 동의** (얼굴 노출 여부, 실명/익명, 채널 범위를 명시적으로 확인)

## 2. 원자료 보관

`_testimonials/{이름 또는 이니셜}_{YYYYMM}.md` 형식으로 저장한다.

```markdown
# 수강생 후기 — {이니셜} ({YYYY-MM})

## 기본 정보
- 코칭 기간:
- Before: {키}cm / {체중}kg
- After: {체중}kg (+{증가}kg)
- 활용 동의: 얼굴 노출 O·X / 실명 O·X / 채널 범위:

## 인터뷰 답변
(12문항 원문 그대로 — 다듬지 않는다)

## 콘텐츠 추출 포인트
- 훅 후보:
- 공감 문장:
- 반전 문장:
- 자립 증거:

## 발행 이력
- [ ] 카드뉴스
- [ ] 스레드
- [ ] 쇼츠
- [ ] 상세페이지
```

원문은 절대 다듬어서 저장하지 않는다. 수강생의 어색한 표현이 가장 진짜처럼 읽히는 카피 원료다.

---

## 3. 4채널 분기 매핑

| 채널 | 쓰는 답변 | 형식 | 전환 단계 |
|------|----------|------|----------|
| **카드뉴스** | 1·2·9·10 | Before-After형 5~7장, 1슬라이드 1메시지 | 고민 → 신뢰 |
| **스레드** | 2·5·7 | 유형 1(스토리형), F주제 | 관심 → 고민 |
| **쇼츠** | 1·6·9 | 포맷 5(코칭결과), 훅 A(미스테이크) 또는 C(반직관) | 인지 → 관심 |
| **상세페이지** | 4·11·12 | 인용문 + Before/After 수치 | 신뢰 → 전환 |

**분기 원칙**
- 한 후기를 4채널에 동시 발행하지 않는다. 최소 3~4일 간격을 둔다. 같은 사람 이야기가 몰리면 광고로 읽힌다.
- 채널마다 **다른 답변**을 쓴다. 같은 문장을 재탕하면 팔로워가 알아챈다.
- 4번(망설임)과 7번(힘들었던 순간)을 뺀 후기는 신뢰도가 급락한다. 반드시 하나는 넣는다.

## 4. 가드레일 (반드시 검증)

**동의 확인**
- 저장된 활용 동의 범위를 넘어서 쓰지 않는다. 동의 항목이 비어 있으면 **콘텐츠를 만들지 않고 사용자에게 먼저 확인을 요청한다.**
- 익명 요청 시: 이니셜·나이대·직업군까지만. 특정 가능한 조합(회사명 + 지역 + 나이)은 금지.

**과장광고 (표시광고법)**
- 후기를 일반화하지 않는다. "3개월에 10kg 증량 가능"(X) → "○○님은 3개월간 10kg 증가했습니다"(O)
- 후기 콘텐츠에 **"개인에 따라 결과가 다를 수 있습니다"** 고지를 포함한다.
- Before/After 사진: 보정·조명 조작·자세 과장 금지. 각도가 다르면 다르다고 표기한다.

**사실 검증**
- 수강생이 잘못된 지식을 말한 부분은 그대로 인용하지 않는다. 브랜드 사실 오류 3종 규칙 적용:
  - "운동 후 30분 이내 단백질" → "1~2시간 이내" 또는 "하루 총량 기준"
  - "벌크업의 X%는 식단" → "운동(자극) + 식단(재료), 둘 다 필수"
  - "칼로리를 줄이고" (벌크업 맥락) → "칼로리 잉여를 유지하면서"
- 수치는 원자료와 대조한다. 반올림해서 부풀리지 않는다.

**브랜드 규칙**
- 계정 표기는 `@bulk_farmer` (한글 @벌크농부 금지)
- 말투: 짧은 문장, 줄바꿈, 경어체, 수치 직접 언급, 이모지 최소

## 5. 작업 순서

```
1. 후기 원자료 확인   _testimonials/ 조회 또는 사용자 제공 자료 접수
2. 동의 범위 확인     비어 있으면 여기서 중단하고 질문
3. 채널 결정         요청받은 채널 또는 발행 이력상 비어 있는 채널
4. 추출              해당 채널 매핑 답변만 뽑는다
5. 초안 작성         채널별 규격은 해당 제작 문서 참조
                    (card_news_agent / threads_template / shortform_agent)
6. 가드레일 검증      동의·과장·사실·수치 4항목 체크
7. 이력 기록         원자료 파일의 발행 이력 체크박스 업데이트
```

완료 후 반환값에 **어떤 답변 번호를 썼고 어느 채널이 아직 비어 있는지** 1줄로 요약한다.
